Credenciales de Reddit (API)
Cómo obtener Client ID y Secret (gratis):
  1. Entra en https://www.reddit.com/prefs/apps (debes estar logueado).
  2. Baja y pulsa “create an app” / “Create Another App”.
  3. Rellena: name = explorador-de-redit · tipo = script · redirect uri = http://localhost:8080
  4. Pulsa create app. Copia el client id (debajo del nombre) y el secret.

Solo aplica con credenciales. 30 es un buen equilibrio velocidad/completitud.
